# Create Blazor Pie, Pyramid, and Funnel Charts in Just 10 Minutes

A quick Blazor sample showing how to add accumulation charts (pie, pyramid, funnel) to a Blazor WebAssembly app.

A quick start Blazor project that helps you learn how to add a simple Blazor accumulation chart to a Blazor WebAssembly app. In the included video and sample you will see how to populate list data and set series types for charts. You will also learn how to add legends and enable data labels and tooltips in Blazor accumulation charts.

**Example**: https://blazor.syncfusion.com/demos/chart/pie

**Documentation**: https://blazor.syncfusion.com/documentation/accumulation-chart/getting-started

## Prerequisites

- Visual Studio 2022

## Features

- Pie, Pyramid, and Funnel accumulation charts
- Populate series from list data
- Legends, data labels, and tooltips enabled

## How to run the project

1. Checkout this project to a location on your disk.
2. Open the solution file using Visual Studio 2022.
3. Restore the NuGet packages by rebuilding the solution.
4. Run the project.

## Usage

Explore the sample pages to see how series data is created and bound to the accumulation chart components. Adjust series types and label settings to experiment with different visualizations.
